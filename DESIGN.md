# ZINC interface
A calm aquatic canvas: rich ocean blue (#126bc5 → #063774), white rounded panels, ink #12365b, muted #526b84, rules #d6e7f5 and 24px corners. Manrope headings and DM Sans body text. The blue canvas frames the work; pale panels hold detailed content.

## Components
- Overview: four completion cards (four across desktop, two across phone), a highlighted next activity, and a separate next-week panel.
- Week: one card per dated activity, plain status words, distinct Strong / Moderate / Emerging evidence badges, and a compact rescheduling expander.
- Train: movement illustration, current version and prescription, written cue, display-only easier/harder examples, source popover and a matching feedback form. Timers are optional aids and record nothing.
- Progress: completion percentage, dated activity curve, baseline completion separate from extras, and contextual feedback tables. No health score.
- Coach: plain-text history in distinct bubbles, suggested prompts, and an explicit next-week proposal with separate Accept and Decline controls. Model text remains inert; the typing effect uses escaped, filtered text.
- Navigation: five equal native radio tabs, icons above short labels, filled selected pill, retained keyboard arrow navigation and visible focus. Bottom space is reserved for the dock and chat input.
- Stop: compact red control outside active training; prominent red outlined control during unfinished training. Available on every planned page. Symptom handling and session lock are unchanged.
- Header: one wordmark, fictional-data label, accessibility settings and a small Demo menu. Welcome precedes the three onboarding steps; the sidebar is only exposed with ?demo=1.
- About: adaptation rules, evidence sources and limits. Fictional data and session-only storage remain explicit.

## Accessibility
48px minimum controls, text on every status/evidence badge, meaningful illustration alt text, a large text option, solid high-contrast surfaces, reduced-motion breathing/timers, and native keyboard semantics. Responsive checks cover 1280px, 390px and 360px widths. These checks are not a formal accessibility certification.

## Scope
This pass improves presentation, not clinical validation or public-service readiness. Accounts, durable storage, clinical clearance, notifications, and a native application remain outside the build plan.
